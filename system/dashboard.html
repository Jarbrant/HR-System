Systemstart

SYSTEM_ADMIN sätter upp systemet (org + assignments). Det här behöver vara klart innan admin-/manager-sidor kan användas.

Inloggad: — • Roll —

Status

Org: — Assignments: — Nästa steg: —

Vanligt upplägg: Root → Bolag → (Enhet) → Team. Scope sätts på Bolag eller Enhet.

1) Skapa bolag

Skapa minst ett bolag under Root. Det blir din första scope-nod.
Öppna Org Builder
./org.html

2) (Valfritt) Skapa enhet

Skapa enhet under bolaget om du vill dela upp scope per avdelning (t.ex. kök, servering).
Skapa enhet i Org Builder
./org.html

3) Koppla roll + scope

Koppla empNo → roll + scopeId (scopeId = bolag eller enhet). Krävs för att ADMIN/MANAGER/EMPLOYEE ska fungera.
Öppna Assignments
./assignments.html

Snabb test

När org + assignments är klara: logga in som ADMIN/MANAGER och öppna en admin-sida som kräver scope.
Om något låser: kontrollera att scopeId pekar på befintlig nod.

Checklista (måste vara klar)

  • Org har minst 1 nod under root (t.ex. ett bolag)
  • Varje empNo som ska logga in har en assignment (roll + scopeId)

Om någon säger “tasks funkar inte” är det nästan alltid att assignments saknas eller att scopeId pekar på fel nod.

Vanliga fel (snabb felsökning)

  • Admin-sidor säger subtree/scope saknas → assignments saknas eller scopeId saknas/fel
  • Tasks kräver scope → org saknas eller scopeId pekar på ogiltig nod
  • Employee ser inget → saknar assignment eller scopeId pekar på “fel nivå”
