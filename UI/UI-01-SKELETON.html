Testdata (för att kunna logga in)

Systemet är fail-closed. Om org/assignments saknas fungerar ingen inloggning. Skapa minimal testdata så att du kan testa rollerna (PIN enligt AO-AUTH-PIN-V1): 9000 (SYSTEM_ADMIN), 3001 (ADMIN), 2001 (MANAGER), 1234 (EMPLOYEE).

Tips: du kan också öppna login med ?seed=1 för att försöka skapa detta automatiskt (endast om data saknas/är korrupt).
