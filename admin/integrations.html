Så gör du (säkert)
1) Lägg API-nyckeln som SECRET i din Worker (inte i GitHub Pages).
2) Workern exponerar ett endpoint som /pk/status som returnerar
{ configured: true/false, maskedKey: "pk_****1234" }
3) Denna sida visar bara status + maskad nyckel.
