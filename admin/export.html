Plans Export → Packages

1) Välj färdig plan

—
Filtrerar listan lokalt.
Export bygger paketets blocks från AO-057_TRAININGS_V1 (training.blocks). Om en training i planen saknar blocks (eller ej finns) blir export fail-closed.

Planpreview

Preview visar vilka trainings som hittas och hur många blocks som exporteras.

2) Exportinställningar

—
Endast om ORG saknas och du är SYSTEM_ADMIN.
Default fylls från planens titel.
Export gör en upsert i AO-050_PACKAGES_V1: - id = pkg_plan_{planId}
- isActive = true
- scopeId = vald/inskriven
- blocks = från planens trainings (sammanfogade)

Resultat

Read-only preview tills du klickar “Exportera”.
